# Legal Domain Pack (reference artifact)

`manifest.json` is a schema-1 reference pack for a matter workflow. It declares
intake, research, drafting, citation review and human approval roles and stages,
along with artifacts, evidence, a validator reference, knowledge guidance,
governance policy and an optional read-operation need. These entries are data
only: they do not register an adapter, grant access, approve a matter or run a
Runtime pipeline.

The pack is exercised through a test-supplied local catalog. It is not
registered in the production catalog, no project adopts it, and it offers no
legal service or filing integration. See the
[Domain Pack contract](../domain-pack-contracts/README.md) and the
[M16 plan](../../docs/development/generic-core-domain-packs.md).
